# Research Papers - LLM Quantitative Finance

This directory contains research papers, literature reviews, and bibliographic references for LLM applications in quantitative finance.

## Paper Categories

### 1. Financial Analysis and Prediction

#### Price Prediction & Forecasting
- **"Fine-Tuning Large Language Models for Stock Price Prediction"** (2024)
  - Focus: Using LLMs to predict stock prices from news and financial reports
  - Key Methods: Prompt engineering, few-shot learning, ensemble approaches
  - Tags: `price-prediction`, `fine-tuning`, `forecasting`

- **"Transformer-Based Models for Multi-Horizon Financial Forecasting"** (2023)
  - Focus: Temporal Fusion Transformers for multi-step ahead predictions
  - Key Methods: Attention mechanisms, temporal convolutional networks
  - Tags: `time-series`, `multi-horizon`, `transformer`

#### Financial Document Analysis
- **"Automated Financial Statement Analysis with Large Language Models"** (2024)
  - Focus: Extracting financial ratios and insights from 10-K filings
  - Key Methods: Document understanding, information extraction, named entity recognition
  - Tags: `financial-statements`, `10-K`, `information-extraction`

- **"Earnings Call Analysis: NLP Approaches for Investment Signals"** (2023)
  - Focus: Sentiment and information extraction from earnings transcripts
  - Key Methods: Sentiment analysis, question answering, summarization
  - Tags: `earnings-calls`, `sentiment`, `qa`

### 2. Risk Management and Portfolio Optimization

#### Risk Assessment
- **"LLM-Based Credit Risk Assessment from Alternative Data"** (2024)
  - Focus: Using language models to assess credit risk from non-traditional sources
  - Key Methods: Transfer learning, multi-modal learning, feature engineering
  - Tags: `credit-risk`, `alternative-data`, `transfer-learning`

- **"Operational Risk Detection in Banking Using Transformer Models"** (2023)
  - Focus: Identifying operational risks from internal reports and communications
  - Key Methods: Anomaly detection, pattern recognition, classification
  - Tags: `operational-risk`, `anomaly-detection`, `banking`

#### Portfolio Optimization
- **"Natural Language Constraints for Portfolio Optimization"** (2024)
  - Focus: Converting textual investment policies into optimization constraints
  - Key Methods: Constraint extraction, mathematical programming, LLM parsing
  - Tags: `portfolio-optimization`, `constraints`, `optimization`

- **"Black-Litterman Model Augmented with LLM Views"** (2023)
  - Focus: Generating prior views from analyst reports using LLMs
  - Key Methods: View generation, confidence estimation, Bayesian inference
  - Tags: `black-litterman`, `views`, `bayesian`

### 3. Market Sentiment Analysis

#### News & Social Media
- **"Multi-Source Sentiment Analysis for Market Prediction"** (2024)
  - Focus: Combining news, social media, and analyst reports for sentiment
  - Key Methods: Multi-modal fusion, attention mechanisms, ensemble learning
  - Tags: `multi-source`, `sentiment-fusion`, `ensemble`

- **"Twitter Sentiment and Cryptocurrency Returns: A Causal Analysis"** (2023)
  - Focus: Causal relationship between social sentiment and crypto prices
  - Key Methods: Causal inference, sentiment analysis, time-series analysis
  - Tags: `crypto`, `twitter`, `causal-inference`

#### Central Bank Communication
- **"Decoding Fed Communications: NLP for Monetary Policy Analysis"** (2024)
  - Focus: Extracting policy signals from FOMC statements and minutes
  - Key Methods: Text classification, named entity recognition, tone analysis
  - Tags: `central-bank`, `fomc`, `monetary-policy`

### 4. Survey & Review Papers

  - Covers all major applications, challenges, and future directions

## Bibliography Management

Papers are organized with the following metadata:
- **Title**: Paper title
- **Authors**: Author list
- **Year**: Publication year
- **Venue**: Conference/journal name
- **DOI/URL**: Link to paper
- **Tags**: Relevant tags for filtering
- **Summary**: Brief abstract
- **Key Methods**: Main techniques used
- **Results**: Main findings
- **Code**: Link to implementation (if available)

## Adding New Papers

When adding new papers to this repository:

1. Create a new markdown file with the paper title
2. Include all metadata fields listed above
3. Add appropriate tags from the taxonomy
4. Link to any available code or data
5. Add to the appropriate category in this README

## Citation Format

We use APA format for citations. Example:
```
Author, A. A., & Author, B. B. (2024). Paper title. Journal Name, Volume(Issue), pages. DOI
```
