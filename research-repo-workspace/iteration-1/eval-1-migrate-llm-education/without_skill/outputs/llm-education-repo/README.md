## Research Focus Areas

- **Priority 1**: LLM-powered educational applications (tutoring systems, assessment tools, learning analytics)
- **Priority 2**: Evaluation methodologies and learning outcome measurements
- **Priority 3**: Foundational work on LLM capabilities and limitations in education

---

## Tag System

Papers are classified using:
- **Application Domain**: Personalized_Learning, Intelligent_Tutoring, Assessment, Content_Generation
- **Educational Level**: K12, Higher_Ed, Corporate, Lifelong_Learning
- **Technical Approach**: Fine_Tuning, RAG, Prompt_Engineering, Multi_Agent
- **Research Type**: Empirical, System, Survey, Case_Study

See [classification-guide.md](classification-guide.md) for complete tag definitions.

## Usage

For AI-assisted paper discovery and management:
